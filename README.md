## 📸 LAB DOCUMENTATION

Each completed lab will be documented using a consistent reporting format.

| Documentation | Description |
|---|---|
| 📌 Lab Overview | Lab name, category, and objectives |
| ⚙️ Environment | Operating systems and tools used |
| 🔍 Enumeration | Discovery and information gathering |
| 🧪 Methodology | Technical procedures and commands |
| 📷 Screenshots | Relevant evidence and results |
| 📊 Findings | Identified vulnerabilities and observations |
| 📝 Lessons Learned | Skills and knowledge gained |
